# E2A Tool – Privacy Policy

**Last updated: October 14, 2026**

## 1. Introduction

E2A Tool is a Chrome extension designed to assist users working on the EWOQ Rating Portal with task time tracking, productivity statistics, notifications, and workflow automation.

This Privacy Policy describes how E2A Tool processes and stores user information.

## 2. Information We Process

### Task and Productivity Data

E2A Tool processes task-related information, including task duration, task categories, working time, and productivity statistics.

All task-related data is stored locally in the user's browser. This data is not transmitted to the developer's server or any third-party service.

### User Preferences

Extension settings and preferences are stored locally in the user's browser.

### Email Address

E2A Tool uses the user's email address solely for account identification and access authorization.

The email address is transmitted to the developer-operated authentication server for verification. It is not used for advertising or analytics.

## 3. How We Use Information

Information is processed only to provide the extension's functionality:

- Tracking task duration and working time.
- Generating productivity statistics.
- Providing task notifications.
- Supporting workflow automation.
- Saving user preferences.
- Verifying access authorization.

## 4. Data Storage and Retention

Task data and extension settings are stored locally in the user's browser.

Users can remove locally stored information through their browser's extension storage controls.

Email addresses may be processed or retained by the authentication server for access verification. Users may contact the developer to request deletion of authentication-related information, if retained.

## 5. Data Sharing

E2A Tool does not sell user data or share it with third parties for advertising or analytics.

Task-related data remains in the user's browser and is not uploaded to external servers.

Email addresses are transmitted only to the developer-operated authentication server for access verification.

## 6. Third-Party Websites

E2A Tool interacts with the EWOQ Rating Portal but is independently developed and is not affiliated with or endorsed by its operators.

The extension does not use third-party analytics or tracking services.

## 7. Data Security

E2A Tool limits task-data storage to the user's local browser.

Authentication-related information is processed by the developer-operated server. No electronic storage or transmission method can be guaranteed to be completely secure.

## 8. Changes to This Policy

This Privacy Policy may be updated when the extension's functionality or data processing practices change.

Updates will be published on this page.
